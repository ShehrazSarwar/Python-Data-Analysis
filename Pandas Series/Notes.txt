What is Pandas?
Pandas is a fast, powerful, flexible and easy to use open source data analysis and manipulation tool, built on top of the Python programming language.

There are two data structures in Pandas:
1) Series
2) DataFrame

let's start with Series:
Pandas Series is like a column in a table. It's like a one-dimensional array like object containing sequence of values.

To work with pandas first we need to import libraries needed
# Importing Pandas & NumPy
import numpy as np
import pandas as pd


Let's check different ways to create Panda Series
1) From a list:

# String ---> most of the time dytpe of string is object
country = ['Pakistan', 'India', 'Usa', 'Korea', 'Japan']
pd.Series(country)

Seires have index on the left and the values on the right.


# Integer
runs [30,50,87,10,1,90]
pd.Series(runs)


We can override default index also
# Custom index
marks = [99,97,98,95,97]
courses = ['Financial Accounting','Linear Algebra','Data Structures & Algorithms','App of ICT','OOP LAB']
pd.Series(marks, index = courses)

There are two attributes, which you can use to give name to your panda series object and to your pandas series index.
marks = pd.Series(marks, index=courses, name= 'Shehraz Marks')
marks.index.name = 'Courses'
marks

2) From a dict: keys = index

marks = {
    'Eng' : 87,
    'Maths' : 97,
    'Science' : 76
}

marks_series = pd.Series(marks,name = 'Shehraz Marks')
marks_series

7) Series Indexing:

# integer postive indexing
x = pd.Series([1,23,231,54,4,10])
x[3] # 54

# negative indexing incase of non-custom indexing will through a KeyError
x[-1] # not allowed on non-custom indexing


# integer indexing not works on custom indexing having index type other than integer
movie[1] # not allowed

# We can use iloc[] which provide integer based indexing even if the indexing is of type string or any other
movies.iloc[0] # 'Vicky Kaushal'
# Similarly we can use negative indexing with the help of iloc[]

# string indexing same like dict key
movies['Uri: The Surgical Strike'] # 'Vicky Kaushal'

# fancy indexing
