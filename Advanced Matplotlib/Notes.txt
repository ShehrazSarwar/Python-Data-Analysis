- 2D Line Plot: For Bivariate Analysis

plt.plot(x,y)
plt.ylabel('')
plt.xlabel('')
plt.title('')
plt.show()
plt.xlim(val,val)
plt.ylim(val,val)
plt.legend()

for line plot:
we have hidden parameters:
linestyle ---> dotted, dashdot, solid etc
linewidth ---> single integer

multiple lines plot:
plt.plot(x,y)
plt.plot(x,y) X-Axis Col should be same

- for all:
color --> hex or color ---> string
markersize ---> single integer
marker ---> 'D','o', '.' etc
label ---> work only when this method called: plt.legend(loc='best')
plt.grid()
plt.text()

- Scatter plot: For Bivariate and Multivariate (all numerical)
plt.scatter(x,y)

parameters:
s= column for size
c= column for color --> alpha for opacity control (in float or int)
cmap = 'String' for adding different color styles
both are used to show the relation in data better
plt.colorbar()

plt.axhline(val,color='any') & plt.axvline(val,color='any')

- for adding text annotations(for all plots):
plt.text(xdim, ydim, s = string column)
fontdict = {family: '', color: '',size: }) used in title, xlabel and text


- Bar Chart: for Bivariate Analysis
plt.bar(x,y)
plt.barh(x,y) for horizontal bar char
same parameters like color etc
can pass list in color also for setting color of each bar

- plt.xticks() for all plots ---> changing x-axis labels name and rotation

Stacked Barchat:
plt.bar(x,y)
plt.bar(x,y, bottom = upper bar y column)
plt.bar(x,y, bottom = sum of all upper bar y columns)
define labels for charts for better understanding 


Multiple barchart at once:
x = np.arange(len(df)) define x axis using array np.arange method(using lenght of df)
use width small like 0.2 for better visibility
plt.bar(x - 0.2,df['2015'], width = 0.2,label='2015')
plt.bar(x ,df['2016'],width = 0.2,label='2016')
plt.bar(x + 0.2,df['2017'],width = 0.2,label='2017')
plt.xticks(x, df['batsman'])
plt.legend()
plt.show()


- histogram plot: For Univariate Analysis
plt.hist(df['abc'],bins=[any]) --> bins parameter is optional!
plt.hist(df['abc'],log=True) ---> if any outliers use log scale

- pie chart: For Bivariate and Univariate
plt.pie(df['abc'])
parameters:
autopct = '%0.1f%%'
colors = []
labels = [] or any column from df
explode = [floats]
shadow = True ---> For better styling
no need for plt.legend()

- subplots
fig, ax = plt.subplots()
parameters:
figsize (accepts tuple)
nrows and ncols for multiple plots at once
sharex = True (if x-axis is same in all plots)

to use
ax.plot() or any plot same method like plt just ax
and paramets like color, linestyle etc are same
for setting labels texts etc use set_
ax.set_ylabel() or set_xlabel() and ax.set_title()
ax.set_xticks(old label)
ax.set_xticklabels(new label) ---> paramter ----> rotation
fig.show() just like plt.show()
for label showing it's same plt.legend()

if having 2D dimentions like 2 rows and 2 columns use 2D Array indexing to access each plot
ax[0,0] for first one
ax[0,1] for 2nd one and so on
